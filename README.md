# Klokani — TJ Bohemians Praha (Vanilla verze)

Lehká a rychlá webová prezentace pro plavecký oddíl TJ Bohemians Praha ([boh.cz](https://boh.cz)).

## 💡 Vlastnosti

- **Čisté HTML5, CSS a moderní vanilla JavaScript** (žádné frameworky, žádné `node_modules`).
- **Hybridní úložiště:** Funguje 100% samostatně v prohlížeči (`localStorage`) i s volitelným PHP backendem (`SQLite`/JSON).
- **Kompletní obsah:** Závody, aktuality, rekordy oddílu, kontakty, fotogalerie, intranet i administrace.

## 🚀 Jak spustit lokálně

Stačí spustit přiložený skript:
```bash
./run_local.sh
```
A otevřít v prohlížeči: `http://localhost:8080`.
Nebo můžete přímo otevřít soubor `index.html` v libovolném webovém prohlížeči.
