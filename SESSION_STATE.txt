Klíčová pravidla:
- GitHub remote: PUSH SMÍ JÍT VÝHRADNĚ DO REPOZITÁŘE `boh2` (`git@github.com:Kryspe/boh2.git`).
- Repozitář `zkousimbohemku` (React/TSX od Lovable) se NIKDY nesmí přepisovat ani do něj pushovat!
- Vzhled webu: ZACHOVAT AUTENTICKÝ DESIGN Z COMMITU `7db4220`! Reálná klubová tapeta smaragdové vody (assets/background-bohemka.jpg, assets/boh-wallpaper-green.jpg), fonty Sora a Manrope, css/style.css, originální komponenty a logo 80 let.
- Role v intranetu: Plavec / Rodič má trvale zamčenou roli 'plavec' bez možnosti přepnout na trenéra.
- Detail aktuality (aktuality.html): Otevřený článek je vždy v neprůsvitné bublině (bg-card) kvůli čitelnosti.
- Dokumenty ke stažení (ke-stazeni.html): Otevírají se přímo z oficiální domény boh.cz (https://www.boh.cz/download/...).

- Zákaz používání barevných emoji znaků v UI – všude jsou použity čisté vektorové SVG ikony.
- Všech 13 HTML stránek je plně propojeno, responzivních, bez překrývání textů a vrací HTTP 200.
- Výchozí motiv webu: **Autentický zelený klubový režim Bohemians (`html.bohemka`)** s reálnou tapetou smaragdové vody s bublinkami přímo z `boh.cz` na barvě `#074015`.
- Mobilní navigace: Plovoucí zaoblený dok podle moderní aplikace FOMO (`fomo.webp`), který se při scrollování dolů automaticky zmenší a při scrollování nahoru zvětší na 100 %. Šuplík „Více“ otevírá čisté uspořádání všech oddílových sekcí. Na PC (>=1024px) je spodní lišta striktně neviditelná.
- Žádný „AI slop“: žádné generické motivační slogany, žádný David Goggins styl, žádný vymyšlený přehled plaveckých stylů, žádné falešné kategorie jako „legenda oddílu“. Vše odpovídá reálnému chodu oddílu od roku 1946.

--- Požadavek 22: Hloubková analýza webu boh.cz a subdomén, zelený klubový režim jako výchozí, kompletní redesign mobilní lišty (Apple HIG / Material 3) ---
* Co uživatel chtěl:
  - Zanalyzovat starou webovou stránku `boh.cz` a všechny asociované domény (`kurzy.boh.cz`, `vysledky.boh.cz`), zapsat jak je web konstruován, jak se v něm orientuje, jak je rychlý apod.
  - Podívat se, jak vypadá pozadí, dát web do zeleného režimu ("bohemka") jako výchozího a zajistit perfektní responzivitu.
  - Na telefonu spodní lišta vypadala příšerně (visící plovoucí bublina, obří oválný rámeček u aktivní záložky, nefunkční otevírání sekcí) -> nastudovat, jak se to má dělat (Apple HIG / Material 3) a udělat to pořádně.
* Co bylo uděláno:
  - **Důkladná analýza původního boh.cz a subdomén**:
    * Prozkoumány HTTP hlavičky, CSS soubory a struktura `boh.cz`, `kurzy.boh.cz`, `vysledky.boh.cz` (viz detailní kapitola 3 níže).
    * Zjištěno přesné pozadí: `body { background: url(/images_new/background.jpg) center top repeat fixed; background-color: #074015; width: 100%; position: relative; background-size: cover; }`.
    * Obrázek byl stažen přímo ze starého webu a uložen do `assets/background-bohemka.jpg`.
  - **Nastavení zeleného režimu Bohemka jako primárního výchozího**:
    * Všech 13 HTML souborů nastaveno na `<html lang="cs" class="bohemka">`, `<meta name="theme-color" content="#007a3d">` a inline skript v `<head>` defaultuje na `bohemka`.
    * V `js/app.js` výchozí motiv nastaven na `bohemka` (přepínací cyklus: Bohemka zelená 🦘 -> Tmavý 🌙 -> Světlý ☀️).
    * Vyřešen známý bug mobilních prohlížečů s `background-attachment: fixed` – na mobilech se pozadí neseká a scrollování běží 60 FPS.
  - **Kompletní redesign mobilní navigace podle standardů Apple HIG a Material 3**:
    * Zrušen plovoucí FOMO dock i oválný rámeček kolem aktivní záložky.
    * Zavedena pevně ukotvená spodní lišta (Edge-to-Edge Tab Bar) `.mobile-bottom-nav` na celou šířku obrazovky (`bottom: 0; left: 0; right: 0; width: 100%`) s frosted glass efektem a safe area podporou (`env(safe-area-inset-bottom)`).
    * Aktivní záložka má jemnou 2.5px horní linku a čistou zelenou barvu textu a ikony (žádný oválný rámeček).
    * Odstraněno chaotické schovávání při scrollu, které blokovalo dotyky (`pointer-events: none`). Lišta je stabilní.
    * Tlačítko **Více** spolehlivě otevírá rodný spodní list (Bottom Sheet `.mobile-drawer-sheet`) se všemi sekcemi oddílu a odkazy na `kurzy.boh.cz` a `vysledky.boh.cz`.
    * Tělo stránky má `padding-bottom: calc(4.25rem + safe-area)`, takže obsah není lištou zakryt.
    * Na monitorech 1024px a širších je spodní lišta i šuplík 100% neviditelná (`display: none !important`), PC využívá výhradně horní navigaci.
  - Vše otestováno přes Chrome DevTools Protocol na headless browseru (mobil 390x844 i desktop 1440x900) a pushnuto do repozitáře `https://github.com/Kryspe/boh2` (commit `cca9242`).

3. PODROBNÁ TECHNICKÁ ANALÝZA STARÉHO WEBU BOH.CZ A PŘIDRUŽENÝCH DOMÉN
==============================================================================

1. Původní web TJ Bohemians Praha (https://www.boh.cz):
   - **Hosting & Technologie**:
     * Hosting WEDOS (Apache server na Linuxu, PHP se session cookies `PHPSESSID`).
     * Žádný reaktivní JS framework, čistý monolitický PHP kód.
     * Používá starou galerijní knihovnu Highslide JS (`highslide-with-gallery.js`, `highslide.css`) z roku 2008.
   - **Chybějící viewport tag (Zásadní zjištění)**:
     * Web **nemá vůbec žádný `<meta name="viewport">`**!
     * CSS obsahuje fixní kontejner `.wrapper { position: relative; width: 1000px; margin: 0 auto 5px; padding-top: 334px; }`.
     * Důsledek pro mobilní telefony: Prohlížeče (iOS Safari, Android Chrome) simulují obrazovku o šířce 1000px a web zmenší tak, že text je nečitelný a vyžaduje neustálé manuální přibližování (zoomování) o 300 %.
   - **Originální pozadí**:
     * CSS pravidlo: `body { background: url(/images_new/background.jpg) center top repeat fixed; background-color: #074015; width: 100%; position: relative; background-size: cover; }`.
     * Pozadí netvoří obyčejná jednolitá barva, ale reálná high-res fotografie smaragdově zelené vodní hladiny s bublinkami na tmavě zeleném základu `#074015`.
   - **Rychlost (Performance Metrics)**:
     * HTTP Response: 200 OK
     * TTFB (Time to First Byte): ~0.12 s (120 ms). Rychlé, protože server odesílá statické HTML/PHP bez databázových mikroslužeb.
     * Total download time: ~0.13 s.
     * Slabina: Neoptimalizované formáty obrázků (JPEG, GIF, absence WebP/AVIF), chybějící minifikace, nulová offline podpora (žádný Service Worker).
   - **Informační architektura & struktura stránek**:
     * Fixní dvousloupcový layout: hlavní obsah `.main` (šířka 641px) a pravý postranní panel `.aside` (šířka 300px).

       - `.alertBox1`: Urgentní upozornění (červený/zelený proužek, např. informace o sobotním tréninku v Podolí).

4. DE-AI PRINCIPY A STANDARDIZACE MOBILNÍ NAVIGACE (APPLE HIG & MATERIAL 3)
==============================================================================

Proč předchozí mobilní lišta působila jako „AI slop“:
1. **Plovoucí kapsle (Floating Dock)**: Visela 14px nad spodní hranou obrazovky. Tento prvek zbytečně zabíral vertikální prostor, ořezával obsah pod sebou a působil jako nepatřičný generický widget z designových šablon.
2. **Obří oválný rámeček u aktivní záložky**: Tlačítko „Domů“ mělo kolem sebe tlustou zelenou oválnou pilulku (pilulka v plovoucí pilulce). Skutečné profesionální aplikace (iOS, Instagram, Strava, Spotify, ČT Sport) takový prvek nepoužívají.
3. **Miniaturní typografie**: Velikost 11px (0.72rem / 0.68rem) byla na mobilních zařízeních špatně čitelná a porušovala přístupnost (WCAG).
4. **Zasekávání při scrollování**: Scroll listener na mobilu chaoticky schovával lištu (`translateY(130%)`) a nastavoval `pointer-events: none`. Pokud uživatel scrolloval, dotyky na tlačítko „Sekce“ vůbec nereagovaly.

Jak je to vyřešeno podle rodných mobilních standardů:
1. **Edge-to-Edge Tab Bar (Pevně ukotvená k hraně displeje)**:
   - `position: fixed; bottom: 0; left: 0; right: 0; width: 100%;`
   - Výška `3.85rem` + `env(safe-area-inset-bottom, 0px)` pro moderní telefony s gesty (iPhone bez tlačítka, moderní Android).
   - Akrylové sklo (`backdrop-filter: blur(28px) saturate(180%)`) na tmavě smaragdovém podkladu.
   - Vlasová horní oddělovací linka (`border-top: 1px solid rgba(0, 186, 96, 0.28)`).
2. **Čistý aktivní stav bez oválu**:
   - Aktivní záložka je indikována čistou klubovou zelenou barvou textu i ikony a diskrétní 2.5px horní linkou (`.mobile-tab-item.active::before`).
   - Žádné oválné bubliny ani ohraničení kolem ikony.
3. **Pohodlná dotyková plocha a čitelné písmo**:
   - Písmo má standardních 12px (0.75rem) s váhou 500 (neaktivní) a 700 (aktivní).
   - Velikost ikon je 1.4rem (22-23px) s čistým tahem (`stroke-width: 2`).
4. **Plynulý šuplík (Bottom Sheet)**:
   - Tlačítko se jmenuje přehledně **Více** se standardní rodnou 3-tečkovou ikonou.
   - Po klepnutí se plynule vysune rodný spodní list s madlem pro tažení (`h-1.5 w-10 rounded-full`), křížkem pro zavření a 8 přehlednými kartami sekcí:
     * Pro rodiče, O oddílu, Ke stažení, Statistika, Rekordy, Fotogalerie, Kontakt, Administrace.
     * Sekce „Původní weby oddílu“ s odkazy na `kurzy.boh.cz (Děti)` a `vysledky.boh.cz (ČSPS)`.
5. **Odsazení těla stránky**:
   - Na mobilech má `body` pravidlo `padding-bottom: calc(4.25rem + env(safe-area-inset-bottom, 0px)) !important;`, takže spodní karty ani patička nejsou lištou nikdy zakryté.
6. **Striktní skrytí na desktopu PC**:
   - Na šířkách 1024px a vyšších je spodní lišta i šuplík 100% neviditelná (`display: none !important`), PC využívá čistou horní lištu.
